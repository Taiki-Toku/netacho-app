# ADR-003 NODAL の見た目への置き換え(状態の持ち方・URL・画像・書体)

- 日付:2026-11-16
- 状態:採用(ベータ版)

## 背景
依頼4(オーナーの `local-data/request4/`)で、画面の見た目と構成を決定済みの試作(`docs/design_reference/nodal-prototype.html`)に合わせ、
仕様は `docs/design_spec.md` を正とすることになった。既存の機能(今日のネタ、詳細、安全なリンク、フィードの読み込み、試験)は残す。
デザイン案の見比べ(`#/design-lab`)と前の配色・部品は捨てる。

## 決定

| 項目 | 決定 | 理由と代わりの案 |
|---|---|---|
| 色・文字の値 | `src/styles/tokens.css` の CSS 変数にまとめ、部品には値を書かない。暗い版だけ(`data-theme` の切り替えは削除) | 仕様 1〜2 章。明るい版と切り替えは作らない(依頼4) |
| 画面の状態と URL | ジャンル `#/genre/<id>?kind=…`、公式のお知らせ `#/feed?kind=…`、脆弱性 `#/vuln?sev=…`、検索 `#/search?q=…` のように、絞り込みと検索語をハッシュの `?…` に持つ(`src/app/router.ts`)。「すべて」のときは `?` を付けない | 仕様 7 章(再読み込み・戻るで元の表示に戻る)。昔の `#/archive`・`#/settings`・`#/design-lab` は「今日」に落とす |
| 絞り込みの部品 | 種類の札や深刻度の件数カードは、ボタンではなく `a`(href に絞り込み後の URL) | URL を変えるのが目的なので、リンクが素直。キーボードと「戻る」がそのまま効く。選択中は `aria-current="true"` |
| 保存・評価・メモ | `src/data/userStore.ts` の `UserStore` にまとめ、いまは端末の localStorage(鍵 `nodal-user`)に保存。React へは Context で渡す | 依頼4 の 8。あとで Supabase に差し替えるときは `createLocalUserStore` と同じ形の実装を作って `App` に渡すだけでよい。ネタに元から付いている `rating` / `memo` は、自分で操作するまで表示に使う |
| 画像の安全 | `imageHref`(`src/lib/safeUrl.ts`)が通すのは、https: の URL と、同じオリジンに解決される相対パスだけ。それ以外と読み込み失敗は頭文字の札 | 依頼4 の 2。`//evil.example/…`・`javascript:`・`data:` は通らない。試験は `src/lib/safeUrl.test.ts` と画面の試験 |
| 見本の画像 | `fixtures/images/*.svg` を `import.meta.glob` でビルドに取り込み、見本のネタの `imageUrl`(`fixtures/images/…`)をその URL に置き換える(`src/data/source.ts`)。本物のデータの URL は書き換えない | 依頼4 の 2(見本の画像は fixtures に置く)。開発サーバーでも dist でも同じ仕組みで表示できる。`@types/node` を足さずに済む(vite の plugin で fs を使う案は型の都合で見送った) |
| 書体 | `@fontsource/dm-sans`(400/600/700)、`@fontsource/noto-sans-jp`(400/600/700)、`@fontsource/space-grotesk`(600)を npm で入れ、`src/main.tsx` で読む。すべて OFL-1.1 | 仕様 2 章(同梱し、外部の配信元を読まない)。Noto Sans JP の `400.css` などは文字の範囲ごとに分けた小さなファイルの集まりで、ブラウザーは画面に出る文字の分だけ取りに行く。500 は画面で使っていないため読まない |
| アイコン | `public/logo/nodal-icon.svg` から `scripts/make-icons.mjs` が favicon(SVG)と PWA のアイコン(PNG 192/512/maskable/apple-touch-icon)を作る。`public/manifest.webmanifest` から参照 | 画像のツールを入れずに済ませるため、形(角丸の四角 + 多角形)だけを自前で描く。正式なロゴが来たら元の SVG を替えて作り直す |
| 骨組み | 1101px 以上:上のバー + 左メニュー + 中央 + 右の列。768〜1100px:右の列を隠し、「今日」に脆弱性ウォッチの帯。767px 以下:上のバー + ジャンルのタブ + 下のメニュー。幅の境目は CSS の `@media` に直接書く | 仕様 3 章。メディアクエリには CSS 変数が使えないため、境目の値(767px / 1100px)だけは直接書く |

## 追加した依存パッケージ(2026-11-16 に npm view と npm の集計で確認)

| パッケージ | 版 | ライセンス | 週間ダウンロード(11/9〜11/15) | 最終更新 | 用途 |
|---|---|---|---|---|---|
| @fontsource/dm-sans | 5.3.0 | OFL-1.1 | 1,164,305 | 2026-07-19 | 本文の欧文(400/600/700) |
| @fontsource/noto-sans-jp | 5.3.1 | OFL-1.1 | 575,647 | 2026-10-11 | 本文の和文(400/600/700。文字の範囲ごとに分けた小さなファイル) |
| @fontsource/space-grotesk | 5.3.0 | OFL-1.1 | 1,141,851 | 2026-07-19 | ロゴの文字(600) |

- 代わりの手段:Google Fonts から読む(仕様が「外部の配信元を読まない」と定めるため不可)、woff2 を手で `public/` に置く(版の更新とライセンスの追跡を自分で行うことになるため見送り)
- 配布元はいずれも fontsource(github.com/fontsource/font-files)。打ち間違いを装った別の名前でないことを `npm view` の repository.url と homepage で確認した
- `npm audit`(追加後):moderate 1 件(minimatch 7.0.0〜11.0.0、typescript-eslint の開発時の依存。今回の追加とは無関係で、以前から同じ)。high 以上は 0 件
- dist の大きさ:約 22MB(書体の woff / woff2 を 3 つの太さぶん含む)。ブラウザーが取りに行くのは画面に出た文字の範囲のファイルだけで、初回の読み込みで全部を取ることはない

## 仕様と違う実装(理由つき)
- 詳細の画面に、仕様 4 章 5 に無い「このネタについて」(コーナー、情報の確かさ、扱い、カテゴリ、取り組み、タグ、星の指標)と前後の移動(ボタン・スワイプ)を残した。依頼4 の「既存の機能は残す」「機能の試験は減らさない」に従うため。見た目は仕様の部品(欄の一覧)で作った
- 記事の行に「評価済み」の文字を添えた。依頼書(docs/beta_brief.md)の「評価済みかどうかが分かる」を残すため
- 左メニューのジャンルは「今日 + 7ジャンル」(仕様は 8 だが、「脆弱性」ジャンルは公式情報の画面に一本化するため出さない)
- 脆弱性ウォッチの帯(768〜1100px)は「今日」だけに出す(試作と同じ)
- 評価の文言は試作のとおり「熱い / 良い / ふつう / いまいち」(依頼書の「刺さった / いいね / 微妙 / いらない」から変更。値 `hot/good/meh/no` は同じ)
