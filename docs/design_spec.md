# NODAL デザイン仕様 v3.7(暗い版のみ。2026-11-17 改訂:地の色、トップ画面、詳細の構成/v3.1:深刻度の英語表記、メニューの区分見出し、画面の文言/v3.2:左メニューの段差、詳細の中央寄せ、媒体名の作り方、要点の出し方/v3.3:スワイプ、画像なしの枠、媒体名の例外、読了バー/v3.4:ジャンルの画像/v3.5:トップの並び、トップの枠の押せる範囲/v3.6:さがすの候補の件数、「先頭へ戻る」の位置/v3.7:「先頭へ戻る」のフェード、スマホの下の余白)

アプリの表示名は **NODAL**(添え書き:Clarity in the Network.)。リポジトリ名やパッケージ名は変えない。
見本は `nodal-prototype.html`(1ファイルで動く試作)。値が食い違うときは、この文書を優先する。
v1(琥珀の案)は破棄。

`color-scheme: dark`、`theme-color` は `#1B1E1B`(上のバーに合わせる)。明るい版と切り替えボタンは作らない。

## 2. 文字

- 本文:DM Sans + Noto Sans JP(400/500/600/700)。ロゴの文字だけ Space Grotesk 600、字間 0.19em。
- すべてアプリに同梱する(外部の配信元を読まない)。
- 大きさ:ページ見出し 26〜34px/600、詳細の見出し 24〜34px、記事の見出し 16px/600、本文 16px・行間 2.0、補助 12〜14px。**12px 未満は使わない**。
- 見出しは `text-wrap: balance`、点数や件数は `font-variant-numeric: tabular-nums`。
- 英大文字の小見出しは使ってよい(12px、`--muted`、字間 0.12em 前後)。見出しの上の飾りの札(線+文字など)、文末の「→」、「・」でつないだ補助情報は使わない。

## 3. 骨組み

| 幅 | 配置 |
|---|---|
| 1101px 以上 | 上のバー(72px)+左メニュー(232px)+中央(最大 820px)+右の列(280px) |
| 768〜1100px | 右の列を隠し、中央に「脆弱性ウォッチ」の帯を出す |
| 767px 以下 | 上のバー(60px)+横に流れるジャンルのタブ(トップ+7ジャンル)+下のメニュー(ホーム/公式情報/脆弱性/保存) |

- 左メニュー:GENRES(トップ+7ジャンル)、OFFICIAL(公式のお知らせ、脆弱性)、LIBRARY(保存)。区分見出しは英大文字の小見出しで、押せる項目と見間違えない大きさ・色にする(押せない見た目、上に余白)。項目は区分見出しより約 16px 右に下げ、段差で区分の範囲を示す(PC の左メニューだけ。スマホは横に流れるタブと下のメニューのまま)。
- 押せる物の高さは 40px 以上、主な操作は 44px 以上。
- 詳細の本文幅は最大 660px で、中央の領域の中で左右中央に寄せる。

## 4. 画面

1. **トップ(ホーム)**:「今日」を統合した画面。一番上にトップ(画像+文章の大きな枠)を置く。見出し「今日のニュース」は画面に出さず、読み上げ用の見出し(h1)としてだけ残す(日付は上のバー、件数はニュース一覧の見出しの横にあるため)。続いて脆弱性ウォッチの帯1本(Critical の件数と最新の CVE、CVSS。押すと脆弱性の一覧へ)、ニュース一覧(全件、番号つきの行。リードを1行)。数字タイルを並べる冒頭は作らない。
2. **ジャンル**:そのジャンルのニュースの一覧。プロダクトだけ、下に公式のお知らせと種類の絞り込み(すべて/リリース/サポート終了/試験/障害)。
3. **公式のお知らせ**:RSS をそのまま並べる。「AIによる要約はしていません」と明記。ベンダーのロゴは使わず、頭文字の札。
4. **脆弱性**:深刻度ごとの件数カードが、そのまま絞り込みボタン(もう一度押すと解除)。カードに CVE 番号、製品、CVSS、状況。個別の画面あり。
5. **ニュースの詳細**:ジャンル名、見出し、出典と日付、保存ボタン、画像(ない時は出典の頭文字の札を出典の横に小さく)、要点(短い箇条3行。「AIがまとめた」と明記。データが配列なら箇条、文字列1つなら段落のまま出し、文を切って箇条を作らない)、元記事の抜粋(原文を手を加えずに引用)、試してみる、気をつけること、出典と元記事へのリンク、評価4つ、メモ、前後のニュース。上のバーの下端に読了バー。見出しの下のリード文と「このニュースについて」の欄は、今の位置のまま置く。
   - 前後のニュースへは横のスワイプで移れる(7章)。
   - 「一覧に戻る」のリンクは1行に独立させ、その下にジャンル名を置く(詰めて並べない)。
   - 「試してみる」の見出しは、ジャンルがセキュリティニュース・プロダクトのときは「確かめること」にする。
6. **保存**:保存したニュースの一覧。名前は全ジャンル共通で「保存」。
7. **さがす**:ニュース、公式のお知らせ、脆弱性を分けて表示。入力中は候補(ニュース/公式のお知らせ/脆弱性/ジャンル)を出す。候補は分類ごとに最大3件(4分類で最大12件)。公式のお知らせの候補は外部リンクにせず、その検索語の結果の画面(`#/search?q=`)へ移す。↑↓・Enter・Esc の案内は PC だけに出す。

共通:出典は媒体名だけを短く出す(例:Zenn。`--muted`、12〜13px)。媒体名は元記事の https の URL のホスト名から作る:先頭の www./docs./blog./news. を外し(例:docs.ollama.com → ollama.com)、よく出るホストは表示名に置き換える。https の URL が無ければジャンル名。外したあとが国の区分だけ(co.jp、ne.jp、or.jp、ac.jp、go.jp など)になるときは外さない(docs.co.jp はそのまま)。頭文字の札は媒体名の最初の1文字を大文字にする(例:O)。公式のお知らせの札も同じく1文字。画面の文言に「ネタ」「今朝」「放送」は使わない(「ニュース」「今日」)。「先頭へ戻る」ボタンは1画面分スクロールしてから出す(どの幅でも出す)。767px 以下では下のメニューに隠れないよう、その上(下のメニューの高さ+`env(safe-area-inset-bottom)`+余白)に出す。1100px 以下では、一番下までスクロールしたときにメモ欄の右下のつまみや「前のニュース/次のニュース」のボタンがこのボタンに隠れないよう、画面の下にボタンの分の余白を足す(ボタンの位置と欄の作りは変えない)。ボタンは出るとき・消えるときに不透明度だけを約 200ms で変えてフェードする(登場アニメをトップの最初の表示だけにする決まりの例外)。消えている間は押せず、キーボードのフォーカスも当たらず、読み上げにも出ない。登場アニメはトップの最初の表示だけ。押すと縮む動き、読了バー、候補が開く動き、「先頭へ戻る」のフェード、スケルトンの光沢、スワイプの動きは `prefers-reduced-motion` で止める(読了バーは隠す。スワイプはアニメーションなしで切り替える)。見本は改善案 v3(https://claude.ai/artifact/GKevgnuLr2NCXNis12uNX7)。

用意する状態:0件、画像なし(頭文字の札)、画像の読み込み失敗(同じ札に差し替え)、読み込み中、通信エラー。

## 5. 画像

- 記事の画像は `filter: saturate(.62) brightness(.82)` で色調をそろえる。
- 画像の使い分け(元記事の画像を最優先。記事ごとに絵を生成したり素材を探したりはしない):

| 場所 | 元記事の画像があるとき | 無いとき |
|---|---|---|
| トップの大きな枠 | その画像 | ジャンルの画像 |
| ニュース一覧の行 | 小さなサムネイル | 画像の場所を取らず文字だけ(出典の横に小さな札) |
| 詳細 | その画像 | ジャンルの画像 |

- ジャンルの画像:7ジャンルに1枚ずつ用意してアプリに同梱する(作風・大きさ・置き場所は ChatGPT の案で決めてから追記する)。用意できるまでは、トップの枠も画像の場所を取らず文章だけで全幅にする。
- 元記事の画像の取得は配信データの側の課題(K-042 案)。
- `img` には `width` `height` `alt` を付け、画面外は `loading="lazy"`。

## 6. ロゴ

`logo/` にある SVG を使う(元画像を目で写したもの。正式版が来たら差し替える)。
- `nodal-mark.svg`:印だけ。上のバーではこの形を、`--ink` と `--accent` で描く。
- `nodal-logo-dark.svg` / `nodal-logo-light.svg`:印+文字。
- `nodal-icon.svg`:アプリのアイコン(favicon と PWA のアイコンの元)。

## 7. 実装で必ず守ること(試作は簡略にしている)

- 記事の行は、見出しを本物のリンク(`a`)にする。行全体を `div` や `article` のクリックにしない。押せる範囲は、リンクの疑似要素(`::after` で `inset:0`)で行全体に広げる。保存ボタンはリンクの外に置き、疑似要素より上(`position:relative; z-index:1`)にする。トップの大きな枠も同じ作りにし、枠全体を押せるようにする。
- ジャンル、絞り込み、検索語は URL に反映し、再読み込みや「戻る」で元の表示に戻れるようにする。
- 日付は `Intl.DateTimeFormat('ja-JP', …)` で整形する。決め打ちしない。
- `:focus-visible` の枠を消さない。`prefers-reduced-motion` を尊重する。`transition: all` を使わない。
- アイコンだけのボタンに `aria-label`、飾りの SVG に `aria-hidden="true"`、通知は `aria-live="polite"`。
- スマホの検索は、虫めがねのボタンを押すと欄が開く形にする(試作は狭い欄のまま)。
- メモは自動保存し、「メモを保存しました」と出す。
- 詳細のスワイプ:記事を指の動きに合わせて `transform` で動かす。最初の約 10px で縦か横かを決め、縦ならスワイプにしない(`touch-action: pan-y`)。画面幅の 25% 以上動かすか速く払えば前後のニュースへ移り、届かなければ元に戻す。移ると URL が変わり、「戻る」で元の記事に戻れる。端(最初・最後)では移らずに戻す。
