方向を一言で

「朝の情報番組の進行表(キューシート)を、片手で読む」。画面の主役は、紺のインクで刷った進行表と、その上に載るテロップ。番組カラーは朝焼けの赤橙を1色だけ使い、強調には黄色のテロップを使う。

番組の文法をそのまま部品にする。見出しはテロップの帯、コーナー(slot)は帯の上に載る傾いた札、一覧は罫線で区切った進行表の行、評価済みは紙の進行表に押す「済」の検印、星の指標は番組のフリップにある5段階メーター。

量産型を避けるための約束:角丸は 2〜4px まで、カードを並べない(行で積む)、絵文字と英字の小見出しを使わない、グラデーションを使わない、色は番組カラー1色と黄色だけに絞る。

画面の骨組み(言葉だけ。画面は承認後に作る)

  • 上端:番組ヘッダー。「AIネタ帳」と放送日(大きな数字)だけの薄い帯。スクロールで縮む。
  • 下端:チャンネル切り替え。今日/バックナンバー/探す/設定の4つを、親指の届く下に固定。
  • その上:ジャンルのタブ。横に並ぶタブを、画面の下半分(下の操作列の直上)に置く。上に置くより片手で切り替えやすい。
  • 今日の放送:進行表の行を順番に積む。評価済みは薄く「済」。行を押すと詳細へ。
  • ネタの詳細:テロップ(コーナー名の札 + 見出しの帯)→ リード → 要約 → 試すなら → 注意(黄色のテロップ)→ メーター → 出典 → 評価・扱い・メモ。前後の移動は下のボタンとスワイプ。
  • バックナンバー:日付ごとの放送一覧。日付を大きな数字で。
  • 探す:検索欄を画面の下寄りに。絞り込みはタブと同じ札で。

決めてほしいこと

  1. 番組カラーは A「朝焼け」(お勧め)か、B「スタジオブルー」か。
  2. 文字は端末のフォントだけでよいか(お勧め)。見出し用の Web フォントを使う場合は、日本語フォントは数 MB あるため、数字だけの欧文フォントを自前で同梱する案に限る。
  3. テロップの傾き(-12°)と「済」の検印は、番組らしさの中心。やりすぎなら、傾きを無くして帯だけにする案もある。
  4. ダークの地を紺寄り(案のとおり)にするか、純粋な黒寄りにするか。
